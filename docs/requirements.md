# 需求說明

## 這是什麼
一個不用註冊登入、具備可愛療癒風格的匿名即時聊天室。所有人在同一個聊天室裡交流。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機、平板來操作。

## 視覺風格（Visual Style）
- 整體走**可愛柔和馬卡龍色系（Pastel / Macaron Style）**。
- 主色調採用**淡粉紅（Pastel Pink）、淡天藍（Pastel Blue）、淡奶黃（Pastel Yellow）**與奶油白。
- 採用大圓角卡片設計、柔和陰影與可愛活潑的按鈕動畫微互動。

## 使用的流程
1. 打開網頁
2. 輸入自訂匿名代號（暱稱）
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. 送出文字訊息或可愛圖片
5. 可對他人訊息點擊表情貼圖（Reactions）互動
6. 可隨時收回自己發出的訊息，或切換不同色系主題

## 畫面上要有
- 頂部可愛狀態列：聊天室名稱、在線人數與在線名單摺疊面板
- 即時狀態提示：成員進來或離開的溫馨小提示
- 訊息對話區：
  - 頭像氣泡、發送者暱稱、發送時間
  - 支援文字內容與圖片預覽
  - 訊息下方的表情回應計數器（預設快捷 👍、❤️、✨、🥺，另可用「＋」自選任何 emoji；每人每則訊息最多 1 種）
  - 自己的訊息提供「收回訊息」按鈕
- 底部輸入區：
  - 快速 Emoji 表情面板開關
  - 圖片上傳/網址發送按鈕
  - 訊息輸入框與可愛發送按鈕
- 頂部功能區：
  - 提供柔和色系主題切換按鈕（粉紅甜心 / 粉藍晴空）

## 不需要的
- 帳號密碼註冊、登入機制
- 收集個人隱私資訊

## 兩個聊天室（後來新增）
打開網頁後，第一個畫面先選身分：「訪客」或「縵」。
- **點「訪客」**，出現兩個選項：
  1. **「好多人」（匿名多人群組）**：只要匿名輸入名稱就能進去，中文、英文、數字、emoji 都可以。
  2. **「兩個人」（只跟我的聊天室）**：輸入名字，欄位旁有小標語「輸入自己的名字」，並要輸入自己預設的數字（代碼）才能進去。只有這個聊天室有悄悄話功能。
- **點「縵」**：要輸入帳號和密碼登入。

- 群組裡的人不能互相加好友，也不能互相私聊。每個訪客只會有兩個聊天室：一個群組，加上一個跟 縵 的聊天室。
- 只有 縵（站長）會有一個群組，加上很多個一對一聊天室，每個訪客各一個。
- 訪客進入後，上方有「好多人」「兩個人」兩個分頁可以隨時切換。
- 訪客第一次開「兩個人」聊天室時，自己設一組代碼（四位或六位數字，預設四位）。之後進去要輸入名字加代碼，換裝置也一樣，就能接回舊對話。進去時會問「要不要記得此裝置」，記得的裝置之後免輸入代碼，之後可以隨時更改。
- 訪客可以清空自己這邊的畫面，但不能刪掉整個對話。
- 一對一聊天室的名字是「兩個人」。
- 縵 的帳號在網站上**第一次登入時建立**，同時被登記為站長（寫進 `site_owner` 清單）。之後誰是站長只看這張清單，隨便註冊的帳號不是站長。
- 縵 登入時會問「要不要記得此裝置」，之後可以在設定裡隨時更改，也可以忘記其他裝置。
- 縵 需要登入才能看到所有人的對話；可以封鎖、解除封鎖、刪除對話，都不會通知對方。
- 縵 的在線狀態與「已讀」預設不公開，可以自己開關。
- 縵 在「好多人」裡跟訪客一樣匿名，沒有特別標記。
- 通知只在網頁開著時有效。

## 新增功能
- **等級 A（畫面效果）**：可愛色系切換（粉紅/粉藍主題）與 Emoji 快捷選擇器
- **等級 B（全員即時同步）**：訊息即時表情回應（Reaction）與「收回訊息」功能
- **等級 C（進階服務與規則）**：圖片上傳與發送展示、防刷屏發言冷卻限制（Rate Limit）
- **頭像**：除了內建的可愛頭像，也可以從自己的相簿選照片，或開啟相機當場拍照作為頭像
- **悄悄話**：**只有「兩個人」有**，「好多人」群組只有一般聊天。在「兩個人」，有「一般聊天」與「悄悄話」兩個模式按鈕。按悄悄話後，雙方進入一段用虛線標示的分段，這一段的訊息在離開畫面或按回一般聊天時消失，之前的一般訊息不受影響
